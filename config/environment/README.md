# Ambiente e dependências

Registro em `colab-versions.json` as versões observadas na execução dos resultados apresentados: Google Colab, Python 3.13.15, NumPy 2.1.3 e scikit-learn 1.6.1. Esse arquivo não é um congelamento completo das dependências.

Para instalação local no Windows com Python 3.12, mantenho `requirements-windows-py312.txt`:

```powershell
python -m pip install -r config/environment/requirements-windows-py312.txt
```

Mantenho esse arquivo como configuração de instalação local. As versões e a plataforma podem influenciar a reprodução exata das métricas.
